# Checklist для метода doRegister

## Регистрация пользователя (doRegister)

### 1. Позитивные сценарии
- [x] Регистрация с валидными данными
- [x] Авторизация после успешной регистрации

---

### 2. Обязательные поля
- [x] Пустой email
- [x] Пустой name
- [x] Пустой password

---

### 3. Валидация email
- [x] Невалидный email (без @)
- [x] Email с пробелами
- [x] Дубликат email

---

### 4. Валидация password
- [x] Короткий пароль (3 символа)
- [x] Пароль из пробелов
- [x] Пароль с пробелами по краям
- [x] Длинный пароль (50 символов)
- [x] Очень длинный пароль (255 символов)

---

### 5. Валидация name
- [x] Name с пробелами по краям
- [x] Name из пробелов
- [x] Name с несколькими пробелами
- [x] Спецсимволы в name

---

### 6. Уникальность
- [x] Дубликат name
- [x] Name в другом регистре
- [x] Дубликат email

---

### 7. Консистентность
- [x] Данные совпадают между API и GUI (email, name)
- [x] Регистрация и авторизация (вход возможен после регистрации)

---

### 8. Обработка ошибок API
- [x] HTTP статус соответствует результату (2xx / 4xx)
- [x] Сообщение об ошибке корректное (без орфографических ошибок)
